# Reels Hub

Личный сайт с популярными короткими видео и музыкой из трендов. Ролики собираются сами, по расписанию, и каждый можно скачать одной кнопкой. Сайт работает на телефоне и на компьютере, есть админка.

Всё бесплатно: сайт на GitHub Pages, сбор на GitHub Actions, скачивание через Cloudflare Workers.

## Как это устроено

| Часть | Где работает | Файлы |
|---|---|---|
| Сайт: лента видео и раздел музыки | GitHub Pages | `index.html`, `assets/` |
| Админка | GitHub Pages, сохраняет настройки в репозиторий | `admin.html`, `assets/admin.js` |
| Сборщик роликов | GitHub Actions, запускается каждый час | `scripts/collect.mjs`, `.github/workflows/collect.yml` |
| Посредник для кнопки «Скачать» | Cloudflare Workers | `worker/worker.js` |
| Настройки | репозиторий | `config/config.json` |
| Собранные ролики и музыка | репозиторий | `data/*.json` |

Сборщик запускается каждый час и сам решает, пора ли собирать: интервал задаётся в админке. Ролики старше срока хранения (по умолчанию 30 дней) удаляются из списка. Закреплённые ролики не удаляются.

## Источники

- **TikTok.** Берутся тренды выбранного региона и, если заданы, ролики по вашим темам. Видео можно смотреть и скачивать без водяного знака. Работает через бесплатный неофициальный сервис tikwm.com. Если он поменяется или перестанет работать, сбор TikTok покажет ошибку в админке.
- **YouTube Shorts.** Работает через официальный API, для него нужен бесплатный ключ (шаг 6). Ролики можно смотреть на сайте, но скачать YouTube нельзя: кнопка откроет ролик на YouTube.
- **Музыка.** Это звуки из собранных трендовых роликов TikTok. Выше в списке те, которые используются чаще. Их можно слушать и скачивать в mp3.
- **Instagram Reels и VK Клипы** пока не подключены: бесплатного стабильного способа для них нет.

## Запуск — один раз, примерно 15 минут

### 1. Включить сайт

В репозитории на GitHub откройте **Settings → Pages**. В поле *Source* выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Бесплатный GitHub Pages работает только для открытого (public) репозитория. В репозитории хранятся только настройки и ссылки, самих видео там нет.

### 2. Разрешить сборщику сохранять результат

Откройте **Settings → Actions → General → Workflow permissions**, выберите **Read and write permissions** и нажмите **Save**.

### 3. Получить токен для админки

1. Откройте https://github.com/settings/personal-access-tokens/new.
2. Задайте имя, например `reels-hub-admin`, и срок действия, например 1 год.
3. В блоке **Repository access** выберите **Only select repositories** и укажите этот репозиторий.
4. В разделе **Permissions → Repository permissions** выставьте:
   - **Contents** — *Read and write*;
   - **Actions** — *Read and write*.
5. Нажмите **Generate token** и скопируйте токен.

Токен вводится один раз на странице `admin.html` и хранится только в вашем браузере.

### 4. Посредник для скачивания (Cloudflare Workers, бесплатно)

Без посредника кнопка «Скачать» просто открывает видео в новой вкладке, а на телефоне его приходится сохранять через «Поделиться». С посредником файл сразу скачивается.

1. Зарегистрируйтесь на https://dash.cloudflare.com.
2. Откройте **Workers & Pages → Create → Create Worker**, назовите его `reels-hub-download` и нажмите **Deploy**.
3. Нажмите **Edit code**, замените весь код содержимым файла `worker/worker.js` и снова нажмите **Deploy**.
4. Скопируйте адрес посредника, например `https://reels-hub-download.<имя>.workers.dev`.
5. В админке откройте **Доступ и скачивание**, вставьте адрес, нажмите **Применить**, затем **Проверить** и **Сохранить**.

### 5. Первый сбор

В админке откройте **Источники видео** и нажмите **Собрать сейчас**. Через 1–3 минуты обновите сайт.

### 6. (Необязательно) YouTube Shorts

1. Откройте https://console.cloud.google.com, создайте проект и включите в нём **YouTube Data API v3**.
2. Перейдите в **APIs & Services → Credentials → Create credentials → API key** и скопируйте ключ.
3. В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**. Имя секрета — `YT_API_KEY`, значение — ваш ключ.
4. В админке включите YouTube Shorts и сохраните.

### 7. (Необязательно) Пароль на сайт

Пароль задаётся в админке, в разделе **Доступ и скачивание**. Это простой замок от случайных посетителей. Сайт и так скрыт от поисковиков. Изменения в админке защищены токеном GitHub, без него сохранить ничего нельзя.

## Что можно менять в админке

- **Источники видео:** включение источников, регион трендов, темы, частота сбора, срок хранения и запуск сбора вручную. Там же видно, работает ли каждый источник.
- **Источники музыки:** включение звуков TikTok.
- **Разделы и меню:** названия разделов, их порядок и видимость.
- **Контент:** поиск по роликам, закрепление наверху и скрытие ненужного.
- **Оформление:** название сайта и основной цвет.
- **Доступ и скачивание:** пароль на сайт и адрес посредника.

После сохранения GitHub обновляет сайт за 1–2 минуты.

## Для разработчика

```bash
node --test scripts/test.mjs        # проверки сборщика на подставных данных
node scripts/collect.mjs --force    # сбор вручную (YouTube: YT_API_KEY=... в окружении)
python3 -m http.server 8000         # посмотреть сайт локально: http://localhost:8000
```

Зависимостей нет: чистый HTML, CSS и JavaScript, а также Node.js 22 для сборщика.
